DENTEM PILOTO — archivos separados
- index.html: estructura y navegación
- styles.css: identidad visual y estilos
- app.js: comportamiento y datos de demostración

Uso:
1. Descomprime la carpeta completa.
2. Mantén los tres archivos en la misma carpeta.
3. Abre index.html en Chrome.

Importante:
- Los datos se guardan localmente en el navegador (localStorage).
- No usar datos reales de pacientes.
- Este prototipo no tiene autenticación ni cumple por sí solo requisitos de historia clínica electrónica.
- La historia clínica es una estructura de demostración inspirada en secciones clínicas comunes; debe validarse por un odontólogo y adecuarse a los requisitos oficiales aplicables antes de uso real.
